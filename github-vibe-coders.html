Project Overview

Publishing a website to GitHub Pages is a real-world workflow with many unfamiliar steps, and for someone who doesn't code, one wrong click on a live tool can feel costly. I designed and built a 9-step interactive system simulation for the GitHub for Vibe Coders micro-learning session on Rise, turning that workflow into scaffolded, performance-based practice.

The simulation was built in HTML, CSS and JavaScript, AI-assisted with Muse, Claude and VS Code.

The Highlight: A Low-Stakes Simulation

Instead of describing the steps, the course lets learners do them. The simulation gives non-coders a safe place to navigate a new tool, make mistakes and get feedback before they touch the real thing.

What learners practice

  • Simulated sign-in
  • Repository setup
  • File upload
  • GitHub Pages configuration
  • A pre-publish safety check before going live

Design features

  • Scaffolded, 9 steps: the workflow is broken into one action at a time.
  • Performance-based: learners complete each step rather than read about it.
  • Step-by-step feedback: each action gets a response, so learners know what happened and why.
  • Pre-publish safety check: practice the habit of checking before anything goes public.

Interactive: click through the steps right here, or open the simulation in its own tab for a larger view.

The Rise Course

The simulation sits inside "Publish and Share Your Creative Projects with GitHub," a three-lesson micro-learning session built in Articulate Rise 360: Getting Started: What is GitHub?, Before You Publish: Check Your Project, and Now: Publishing Your Project on GitHub. The first lesson opens by naming the learner's situation: projects vibe coded with AI that run only on their own computer.
